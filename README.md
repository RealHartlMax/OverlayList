# OverlayList
OverlayList ist ein lokales Open-Source-Tool, das Checklisten via WebSockets als Live-Overlay in OBS einblendet. Das Browser-Dashboard ist netzwerkfähig, plattformübergreifend, zweisprachig (DE/EN) und dank Node.js &amp; Vanilla JS extrem ressourcenschonend. Perfekt für Co-Working-Streams!
